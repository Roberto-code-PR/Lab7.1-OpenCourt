### 🏀 Descripción
OPEN COURT es un blog de baloncesto en inglés comercial donde cualquier persona puede escribir sobre baloncesto.

**Tagline:** *Anything about ball*

**Productos principales:**
- BALL - Premium composite leather
- SNEAKERS - Elite grip XDR traction
- ROBERT'S COURT - Community court in Ponce, PR

El sitio es 100% en inglés comercial, sin referencias locales a equipos.

### 📁 Estructura - 8 Páginas Físicas


1. `index.html` - HOME con carrusel de imágenes (Requisito JS #9)
2. `about.html` - ABOUT - Historia del proyecto
3. `news.html` - NEWS - Noticias de la comunidad
4. `community.html` - COMMUNITY - Lista de posts con localStorage
5. `write.html` - WRITE - Formulario para publicar

8. `contact.html` - CONTACT - Formulario con validación en tiempo real (Requisito #11)
9. `style.css` - CSS personalizado separado (Requisito #5)

### 📌 5 Características Principales de la Estructura HTML5 en OPEN COURT

1.  **Etiquetas Semánticas:** Se utilizaron `header, nav, main, section, article, aside, footer` en lugar de `div`. Esto mejora el SEO, la accesibilidad y cumple con el estándar HTML5 moderno.

2.  **Diseño Responsivo:** Con `<meta name="viewport">` y el sistema de grillas de Bootstrap (`col-md-4`, `container-fluid`), el sitio se adapta automáticamente a móvil, tablet y desktop sin código extra.

3.  **Separación de Capas:** El contenido (HTML), la presentación (style.css externo + Bootstrap) y el comportamiento (JavaScript) están separados. Código limpio y fácil de mantener.

4.  **Optimización y Accesibilidad:** Todas las imágenes usan `loading="lazy"` para cargar solo cuando se ven y `alt` descriptivo para lectores de pantalla. Buena práctica profesional.

5.  **Formularios e Interactividad HTML5:** Uso de atributos nativos como `required`, validación con regex en JavaScript, carrusel con `data-attributes` y persistencia con `localStorage` para una experiencia moderna sin recargar la página.
